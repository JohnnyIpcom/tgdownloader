# Bubble Tea Prompt UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace both existing prompt engines with one full-screen Bubble Tea prompt that provides stable substring completion, serialized Cobra execution, and TUI-native progress output.

**Architecture:** A Bubble Tea model owns the alternate screen, editor, completion rows, transcript, and command lifecycle. Cobra remains the parser and executor. Renderer output is delivered through a context-scoped event sink; ordinary CLI commands keep their existing go-pretty output.

**Tech Stack:** Go 1.26.5 toolchain, Cobra 1.10.2, Bubble Tea 2.0.8, Bubbles 2.1.1, Lip Gloss 2.0.5, gotd, go-pretty.

## Global Constraints

- Keep non-interactive command names, flags, parsing, and output behavior unchanged.
- Use one prompt implementation; remove go-prompt, reeflective, readline, Carapace, fallback code, and `prompt.engine`.
- Peer suggestions use the dialog cache only and match case-insensitive substrings or TDLib ID prefixes.
- Show at most six single-column completion rows; bounded display text must not alter inserted text.
- Execute one command at a time and block editor input until completion or cancellation.
- Bubble Tea is the only terminal writer while prompt mode is active.
- Run `gofmt`; after every bug fix rebuild `tgdownloader.exe`.
- Do not commit or push before user manual review. Plan checkpoints replace commit steps.

```go
func (r *Root) submitPromptCommand(parent context.Context, line string, sink renderer.EventSink) tea.Cmd {
	return func() tea.Msg {
		ctx := renderer.WithEventSink(parent, sink)
		args, err := splitPromptLine(line)
		if err == nil {
			root := r.newPromptRootCmd()
			root.SetOut(renderer.NewEventWriter(sink))
			root.SetErr(renderer.NewEventWriter(sink))
			root.SetArgs(args)
			err = executePromptRoot(ctx, root)
		}
		return promptCommandDoneMsg{Line: line, Err: err}
	}
}
```

`executePromptRoot` recovers panic, converts it to an error with stack logged at
debug level, and never mutates the main CLI command tree.

- [ ] **Step 3: Implement prompt runner**

```go
func (r *Root) runPromptTUI(ctx context.Context, history *promptHistoryStore, username string) error {
	events := make(chan renderer.Event, 256)
	sink := renderer.NewChannelEventSink(events)
	model := newPromptModel(promptModelOptions{
		Username: username,
		Version: r.version,
		Complete: r.completePrompt,
		Submit: func(commandCtx context.Context, line string) tea.Cmd {
			return r.submitPromptCommand(commandCtx, line, sink)
		},
		Events: events,
		History: historyEntries(history),
	})
	_, err := tea.NewProgram(model).Run()
	return err
}
```

The model command waiting on `events` converts each renderer event to a
Bubble Tea message. The parent context is watched by another model command and
causes a quit message when cancelled. Prompt setup/authentication stays outside
alternate screen; the TUI starts only after connection and self lookup complete.
